# 🎬 Что посмотреть

**Подбор фильма на вечер по настроению — свежие фильмы обновляются сами, без API-ключей.**

### ▶️ [Открыть](https://mysik-portfolio.vercel.app/movie-picker/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- Подборки «Новинки», «Популярное» и «Сериалы» — собираются из открытых баз и обновляются каждую ночь
- Поиск по всей базе фильмов, настоящие постеры, описания, жанры, длительность и ссылка на Кинопоиск
- «Классика» — встроенная подборка из 56 лучших фильмов с рейтингами
- Подбор по настроению, фильтры по жанру и десятилетию, сортировка
- Рулетка «Мне повезёт» и список «Посмотреть позже»

## Как устроено

```
app.js          # интерфейс
source.js       # загрузка данных и запасной режим
movies.js       # встроенный каталог «Классика»
api/films.js    # серверная функция Vercel
```

Серверная функция берёт списки фильмов из [Wikidata](https://www.wikidata.org) (SPARQL-запросы: даты выхода, жанры, длительность, ID Кинопоиска), а постеры и описания — из API русской Википедии. Ключи не нужны. Ответы кэшируются на CDN на сутки, а Vercel Cron каждую ночь заранее обновляет списки, поэтому посетители получают данные мгновенно. Если источник недоступен, приложение показывает встроенную подборку.

## Стек

JavaScript (ES-модули), Vercel Serverless Functions + Cron, Wikidata SPARQL, MediaWiki API.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/movie-picker.git
cd movie-picker
python3 -m http.server 8000
```

Через `python3 -m http.server` работает встроенный каталог. Со свежими данными: `npx vercel dev`.
