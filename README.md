# 🎬 Что посмотреть

**Подбор фильма на вечер по настроению — с живыми данными Кинопоиска.**

### ▶️ [Открыть](https://mysik-portfolio.vercel.app/movie-picker/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- Подборки Кинопоиска: популярное, топ-250, сериалы и премьеры текущего месяца — обновляются сами
- Поиск по всей базе Кинопоиска, постеры, рейтинги КП и IMDb, описание и длительность
- Подбор по настроению (жанры), фильтры по жанру и десятилетию, сортировка
- Рулетка «Мне повезёт» и список «Посмотреть позже»
- Встроенный каталог из 56 фильмов на случай, если API недоступен

## Как устроено

```
app.js        # интерфейс
source.js     # данные: API Кинопоиска или встроенный каталог
movies.js     # встроенный каталог
api/kp.js     # серверная функция Vercel — прокси к API, ключ хранится в переменной KP_API_KEY
```

Ключ API никогда не попадает в браузер: сайт обращается к `/api/kp`, а функция добавляет ключ на сервере, разрешает только нужные запросы и кэширует ответы на CDN, чтобы не тратить дневной лимит.

## Стек

JavaScript (ES-модули), Vercel Serverless Functions (Node.js), [Kinopoisk API Unofficial](https://kinopoiskapiunofficial.tech).

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/movie-picker.git
cd movie-picker
python3 -m http.server 8000
```

Локально без ключа работает встроенный каталог. С данными Кинопоиска: `vercel dev` и переменная `KP_API_KEY`.
