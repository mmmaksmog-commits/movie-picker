# 🎬 Что посмотреть

**Подбор фильма на вечер по настроению.**

### ▶️ [Открыть](https://mysik-portfolio.vercel.app/movie-picker/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- 56 известных фильмов: год, жанры, длительность, рейтинг
- Фильтры: настроение, жанр, десятилетие, длительность, поиск
- Рулетка «Мне повезёт» с анимацией
- Список «Посмотреть позже»
- Сгенерированные постеры и ссылка на трейлер

## Стек

JavaScript, CSS Grid, localStorage. Без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/movie-picker.git
cd movie-picker
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.
